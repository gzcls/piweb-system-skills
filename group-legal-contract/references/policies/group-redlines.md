# 集团法务强制红线速查表（`policies/group-redlines.md`）

> **说明**：本文件提炼自《集团法务合同审核要点》（完整版见 `references/kb/checklists/`），汇集集团总部及各板块在合同审核与起草中**每次必查的 35 条刚性合规红线**。凡触发以下红线之一的，原则上应评定为 **🔴 高风险** 并要求整改。

## 一、 通用商事合同强制红线（全合同必查 · 15 条）

| 红线编号 | 红线维度 | 强制核查标准与修改底线 | 核心法规依据 |
| :---: | :--- | :--- | :--- |
| **GR-01** | **主体名称与账户四流一致** | 合同首部、正文、签署页公章、增值税发票抬头及收付款银行账户户名必须完全一致；严禁无合法三方协议向第三方或私人账户付款。 | 《民法典》第470条 |
| **GR-02** | **分支机构签约书面授权** | 对方为分公司、项目部等非独立法人分支机构时，必须取得总公司书面授权委托书，未取得授权不得直接签约。 | 《民法典》第74条、《合同编通则解释》第20-21条 |
| **GR-03** | **新《公司法》实缴与人格穿透** | 大额交易须穿透核查对方认缴/实缴资本（5年认缴期）；对方为一人公司或存在关联混同风险的，宜引入实控人/关联公司连带担保；2024-07-01 后未届期股权转让适用补充责任穿透。 | 《公司法（2023修订）》第23、47、54、88条、法释〔2024〕15号 |
| **GR-04** | **对外担保法定决议核验** | 对方为他人提供保证、抵押、质押或债务加入的，必须依据对方公司章程调取并形式审查其有效的**董事会或股东会决议**，否则构成越权担保无效。 | 《公司法（2023修订）》第15条、《九民纪要》第17-22条 |
| **GR-05** | **严禁法定不可免责事项被排除** | 任何免责或责任上限条款，严禁排除“造成对方人身损害”或“因故意或者重大过失造成对方财产损失”的赔偿责任；数据泄露、知识产权侵权、保密违约应排除在责任上限之外。 | 《民法典》第506条 |
| **GR-06** | **格式条款显著提示与防无效** | 避免出现“我方不承担任何责任”等单方绝对免责或排除对方主要权利的表述，防止被法院依格式条款规则认定无效。 | 《民法典》第496-497条、《合同编通则解释》第9-10条 |
| **GR-07** | **违约金30%司法调减防线** | 约定违约金过高的（超过造成损失 30%），面临法院依职权或申请调减；我方作为守约方应同时列明损失计算口径（直接损失+可得利益+维权费用）。 | 《民法典》第585条、《合同编通则解释》第64-66条 |
| **GR-08** | **“先票后款”与虚开发票连带赔偿** | 我方作为付款方必须明确约定“收到对方开具的合法有效且税率合规的增值税专用发票后 X 日内付款”，并约定因虚开、作废、红冲或异常凭证导致我方进项税额无法抵扣的，对方全额赔偿税款损失、滞纳金及罚款。 | 《民法典》第511条 |
| **GR-09** | **大型企业对中小企业账期与“背靠背”禁令** | 集团下属大型企业向中小企业采购货物、工程、服务时，严禁设置以收到第三方款项为前提的“背靠背”付款条款或明显不合理账期（行政处罚最高 500 万元，且“背靠背”约定直接无效）。 | 《反不正当竞争法（2025修订）》第15、31条、法释〔2024〕11号【库外法源·待人工核实】 |
| **GR-10** | **委托开发知识产权归属反转** | 委托技术开发、软件外包、定制设计合同中，法律默认知识产权归受托方/开发方！我方作为委托方必须**显式约定成果著作权、专利申请权及源码所有权全部归我方单独所有**。 | 《民法典》第859条、《著作权法》第19条、《专利法》第8条（见商业秘密与知产汇编） |
| **GR-11** | **数据安全与个人信息委托处理（790号令）** | 涉及个人信息或重要数据处理的，必须同步签署 DPA 条款，落实对外提供双清单列明、敏感信息单独同意、委托处理记录留存 3 年、重大安全事件与漏洞 24 小时内报告义务；严禁违规爬虫抓取数据。 | 《个人信息保护法》第21、28-30条、《网络数据安全管理条例》（国务院令第790号）第10、12、21条、《网络安全法（2025修正）》第20、61条、《反不正当竞争法》第13条第3款 |
| **GR-12** | **商业秘密 1–5 倍惩罚性赔偿与举证转移** | 保密协议或保密条款应明确保密范围与保密措施，并援引 2025 修订《反不正当竞争法》主张 1–5 倍惩罚性赔偿、500 万法定赔偿及举证责任转移规则。 | 《反不正当竞争法（2025修订）》第10、22、39条 |
| **GR-13** | **争议解决严禁“或裁或诉”与管辖不明** | 争议解决只能二选一（诉讼或仲裁），严禁约定“可向仲裁委申请仲裁或向法院起诉”（导致仲裁约定无效）；仲裁机构全称必须准确唯一；涉及不动产租赁、建工施工的严格遵守不动产所在地法院专属管辖。 | 《民法典》第507条、《民事诉讼法》第34、35条【库外法源·待人工核实】、《仲裁法》第16、18条【库外法源·待人工核实】 |
| **GR-14** | **维权费用承担与司法送达地址确认** | 必须明确约定败诉方/违约方承担守约方支出的**律师代理费、诉讼费/仲裁费、财产保全费、诉讼保全责任保险费、公证费及鉴定费**；并确认首部/尾部地址与电子邮箱为适用于一审、二审、执行程序的有效司法送达地址。 | 《民法典》第584条 |
| **GR-15** | **反商业贿赂“行受贿一体双罚制”条款** | 采购、工程、外包、医疗、物业等合同必须嵌入阳光廉洁条款，覆盖回扣、礼品卡券、旅游赞助等，对齐 2025 修订《反不正当竞争法》单位最高罚 500 万、个人最高罚 100 万的双罚制红线。 | 《反不正当竞争法（2025修订）》第8、24条 |

## 二、 租赁与物业专项强制红线（7 条）

| 红线编号 | 红线维度 | 强制核查标准与修改底线 | 核心法规依据 |
| :---: | :--- | :--- | :--- |
| **GR-16** | **无规划证违建无效与非居住空间禁租** | 未取得建设工程规划许可证的房屋租赁合同绝对无效；居住用途（含园区公寓/员工宿舍）严禁将厨房、卫生间、阳台、过道、地下储藏室、车库单独出租用于居住（违者最高罚10万）。 | 《城镇房屋租赁解释（2020修正）》第2-3条、《住房租赁条例》（国务院令第812号）第7、39条 |
| **GR-17** | **二房东转租授权、期限上限与资金监管账户** | 转租须取得原产权人书面同意且转租期不得超剩余租期；承租长租公寓/二房东房源须核验其住房租赁资金监管账户；次承租人应约定代偿租金抵扣权；出租人发现擅自转租须在知道起 6 个月内提异议。 | 《民法典》第716-719条、《住房租赁条例》第19、43条、《城镇房屋租赁解释》第12条 |
| **GR-18** | **租赁期限20年上限与免租期追回** | 租赁期限不得超过 20 年（超期部分无效）；我方作为出租方提供免租装修期的，必须约定承租人违约提前退租时**全额补交已享受的免租期租金（Clawback）**。 | 《民法典》第705条 |
| **GR-19** | **物业催费严禁停水停电与转供电合规** | 物业催收物业费严禁采取停水、停电、停热、停燃气方式；转供电及公共能耗分摊严禁擅自扩大收费范围、提高电价标准或重复收费。 | 《民法典》第944条第3款、《物业管理条例（2018修正）》第44条、《物业服务纠纷解释》第2条 |
| **GR-20** | **押金扣减法定列举与合法腾退边界** | 必须在合同中明确列明扣减押金的具体情形（无约定情形不得扣减），并将**工商注册地址迁出/注销**作为退押金硬性前提；解除合同腾退须留出合理时间，严禁暴力断水断电逼迁。 | 《住房租赁条例》第10、12条、《城镇房屋租赁解释》第13条 |
| **GR-21** | **装饰装修物四情形归属与双优先权放弃** | 明确区分附合/未附合装修物在期满、无效、违约解除下的归属与折价规则；我方作为出租方须明确约定承租人**同时放弃优先购买权与租期届满优先承租权**。 | 《民法典》第726-728、734条、《城镇房屋租赁解释》第7-11条 |
| **GR-22** | **商场/园区发卡商户资质核验（预付式消费连带防线）** | 商场、写字楼底商出租给餐饮、健身、美容、教培等发卡商户时，出租方必须核验并留存其营业执照与经营资质，防范因未尽形式审查义务在商户跑路时被判承担过错赔偿责任。 | 《预付式消费民事纠纷解释》（法释〔2025〕4号）第6条 |

## 三、 采购与食品安全专项强制红线（4 条）

| 红线编号 | 红线维度 | 强制核查标准与修改底线 | 核心法规依据 |
| :---: | :--- | :--- | :--- |
| **GR-23** | **外观签收与质量终验严格剥离** | 采购合同必须明确约定：“物流收货单或仓库签收单仅代表外包装箱数清点，在任何情况下均不构成买方对货物内在质量合格或技术性能达标的验收确认。” | 《民法典》第620-624条 |
| **GR-24** | **散装液态食品准运与婴配液态乳注册（2025食安法）** | 重点散装液态食品道路运输必须核验准运证、专用容器标识与铅封（三查一核，违者最高罚50万）；婴幼儿配方乳粉及**婴幼儿配方液态乳**必须核验配方注册证，严禁分装或同方异牌。 | 《食品安全法（2025修正）》第41、81、124、132条 |
| **GR-25** | **缺陷产品自身损害与他损一并索赔及十倍惩罚性赔偿追偿** | 采购设备或食品药品发生质量缺陷的，买方有权就缺陷产品本身损害与其他财产损害一并索赔；因供应商原因触发食药惩罚性赔偿的，供应商全额承担并赔偿商誉损失。 | 《侵权责任编解释（一）》（法释〔2024〕12号）第19条、《食品药品惩罚性赔偿解释》（法释〔2024〕9号） |
| **GR-26** | **特许经营“两店一年”与加盟店预付卡资金共管** | 餐饮/零售特许经营须核查“两店一年”及备案；严禁加盟商私自发预付卡或联手“职业闭店人”恶意闭店，预收储值资金必须进总部监管账户“按笔核销”。 | 《商业特许经营管理条例》第7、8条、《预付式消费民事纠纷解释》（法释〔2025〕4号）第5、23条 |

## 四、 建设工程施工专项强制红线（2026《建工解释（二）》全面对齐 · 6 条）

| 红线编号 | 红线维度 | 强制核查标准与修改底线 | 核心法规依据 |
| :---: | :--- | :--- | :--- |
| **GR-27** | **严禁挂靠、转包、违法分包与未批先谈中标** | 无规划许可证、无资质挂靠、转包、违法分包合同无效；出借资质方主张管理费一律不支持；**确定中标人前就工程范围、价款等实质性内容先行谈判且中标，或先签合同再走招投标的，中标合同直接无效**。 | 《建工解释（一）》第1-5条、《建工解释（二）》（法释〔2026〕12号）第1-5条 |
| **GR-28** | **严禁未经竣工验收擅自提前使用** | 发包人未经竣工验收擅自使用的，以转移占有之日为竣工日期，且发包人丧失就使用部分主张常规质量瑕疵的权利（仅地基基础和主体结构除外）。 | 《建工解释（一）》第9、14条 |
| **GR-29** | **工程质量缺陷“通知修复前置”程序** | 因承包人原因致工程质量不符约定，发包人**必须先书面通知承包人限期修复**；未通知修复而直接诉请支付修复费用的，法院不予支持。 | 《建工解释（二）》（法释〔2026〕12号）第16条 |
| **GR-30** | **政府审计/财评 1 年封顶与逾期默示结算** | 未明确约定以审计/财评为准的不予支持；即使约定以审计/财评为准，非因承包人原因超过 **1 年**（自提交竣工结算文件起算）未出具结论的，承包人有权直接申请司法造价鉴定。 | 《建工解释（一）》第21条、《建工解释（二）》（法释〔2026〕12号）第13条 |
| **GR-31** | **建设工程价款优先受偿权 18 个月与折价/代位** | 优先受偿权期限 18 个月（自应付工程款日或变更/结算协议约定给付日起算），范围不含逾期利息、违约金、停窝工损失；承包人切勿轻易签署放弃优先受偿权条款。 | 《民法典》第807条、《建工解释（一）》第35-42条、《建工解释（二）》第17-21条 |
| **GR-32** | **实际施工人跨层索赔阻断与农民工工资先行清偿** | 接受转包/违法分包人不得跨层直接向无合同关系的发包人索赔折价补偿（仅能走代位权诉讼）；但农民工有权直接请求建设单位与总包/分包单位先行垫付清偿拖欠工资，转包/分包给包工头的由承包人直接承担用工主体责任。 | 《建工解释（二）》第6-8条、《劳动争议解释（二）》（法释〔2025〕12号）第1-2条 |

## 五、 劳动用工与安全生产强制红线（3 条）

| 红线编号 | 红线维度 | 强制核查标准与修改底线 | 核心法规依据 |
| :---: | :--- | :--- | :--- |
| **GR-33** | **外包施工与场所出租必签专门 EHS 安全管理协议** | 生产经营项目、场所发包或出租给其他单位的，必须签订专门的安全生产管理协议或在合同中明确各自安全生产管理职责，严禁“以包代管”。 | 《安全生产法（2021修正）》第49条、《侵权责任编解释（一）》第15-18条 |
| **GR-34** | **业务外包（BPO）严防“假外包真派遣”** | 业务外包必须按工作成果/工作量结算，发包方严禁直接对外包员工进行考勤、排班、奖惩等劳动过程管理，防止被认定为事实劳动关系或违法劳务派遣。 | 《劳动合同法》第57-67条、《劳动争议解释（二）》第1-3条 |
| **GR-35** | **竞业限制、特殊待遇服务期与违规弃保无效（法释〔2025〕12号）** | 员工同业竞业违约须返还违约期间已领经济补偿并支付违约金；企业提供落户、高额安家费、股权等特殊待遇可约定服务期违约赔偿；任何“员工自愿放弃缴纳社保、单位发放社保补贴”的约定一律无效，企业补缴社保后有权追回已发社保补贴。 | 《劳动合同法》第22-24条、《劳动争议解释（二）》（法释〔2025〕12号）第10-15、19条 |
