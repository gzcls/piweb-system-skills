# 交付前质检清单

每一项记录为“通过 / 不通过 / 未执行 / 不适用”。只有实际验证过的项才能标“通过”。具体数值以 `SKILL.md` 第 2 节和 `style-guide.md` 为准，本清单不重复列出。
`create_starter.py` 生成的起稿和 `--component-fixture` 夹具不能作为成品验收。

## 1. 内容与数据
- [ ] 已对照用户材料核对事实、结论、单位、时间范围、日期、图表数值、来源和备注。
- [ ] 每页只有一个核心结论，标题是观点句；没有为排版删掉关键结论，也没有改变数据含义。
- [ ] 没有补造财务、业务、人员、日期或公开资料；缺失项已明确标出。
- [ ] 模板英文样例、演示数字、制作说明已清除（`check_deck.py` 没有报告残留）；只有 `汇报人｜汇报日期` 字段或用户同意的待补项可以保留。

## 2. 模板与结构
- [ ] 画布为 10 × 5.625 英寸（16:9），没有混用设计基准坐标。
- [ ] 首页和尾页使用首页背景，正文使用正文背景；完整稿有答谢尾页，局部续改没有重复添加首页或尾页。
- [ ] 首页标题居中；右下角是一行可编辑的 `汇报人｜汇报日期`，模板原有的“演讲人：”“时间：”已删除。
- [ ] 正文标题在顶部标题栏内，白色粗体，没有遮挡左上标签区和 Logo，内容区没有重复标题。
- [ ] 正文从 y=0.84 开始；来源行在 y 5.34，只有文字；没有新增页码、第二套标题栏或 Logo。

## 3. 自动检查（`python scripts/check_deck.py <deck.pptx>`）
- [ ] 没有 error；warning 已逐条修复，或在交付说明中解释原因。
- [ ] 每页卡片数、要点数、图表数、辅助结论数和字号层级都在限制内。
- [ ] 没有低于下限的文字；`HX_*` 圆角对象的半径合规，且同组一致。

## 4. 视觉（必须查看渲染出的 PNG）
- [ ] 已用 `render_visual.py` 渲染全部页面，并逐页查看。
- [ ] 没有溢出、截断、遮挡、异常换行、离页对象或孤字成行。
- [ ] 对齐线、边距、组件尺寸、圆角、描边和间距一致；同组卡片等宽等高。
- [ ] 信息密度合理，没有大片无意义的空白，也没有拥挤；页面之间风格统一但不机械重复。
- [ ] 图表的单位、时间范围、图例、标签和来源清楚；图片没有拉伸、模糊或不当裁切；Logo 没有改色。
- [ ] 全部页面通过后，已执行 `render_visual.py --attest ... --review-notes "..."`。

## 5. 可编辑性与兼容性
- [ ] 文件能被 python-pptx 重新打开；正文不是整页截图；标题、文本、卡片、表格和图表都可以编辑。
- [ ] 背景是可替换的图片，没有宣称背景图里的 Logo 或渐变可以单独编辑。
- [ ] 改版或续改没有丢失必须保留的备注、图表数据或对象。
- [ ] 没有把 XML 校验、python-pptx 解析或 LibreOffice 渲染说成已在 PowerPoint 或 WPS 中实测。

