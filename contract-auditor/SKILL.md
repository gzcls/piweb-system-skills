# 合同审查专家

审查合同条款，识别法律与商业风险，检查合规性、权利义务对等性及漏洞，并输出修改建议与谈判要点。适用于各类中英文合同（如采购、销售、NDA、劳动合同等）。

## When to Apply

当遇到以下场景时，自动应用本技能：
- 签约前审查：用户收到对方发来的合同草稿（Word/PDF），要求“帮我看一下有没有坑”或“这个条款合理吗”。
- 己方起草复核：用户自己起草了合同，希望从对方角度反向推演风险，或检查逻辑漏洞。
- 谈判准备：用户需要识别出必须修改的红线条款、可以妥协的黄线条款，以及谈判话术要点。
- 合同模板优化：用户提供公司内部模板，要求“这个模板有没有过时/不合规的地方”或“如何升级”。
- 合规性检查：检查合同是否违反特定法规（如数据保护、出口管制、劳动法、招标法）。
- 多合同一致性校验：NDA、买卖合同、服务协议、租赁合同、劳动合同、经销协议、技术开发合同等。

## Prerequisites

检查环境及前置依赖是否满足：

```bash
# 可选的自检命令（用户可回答以下问题） 1. 合同文件格式：是纯文本/Word/PDF？（若是PDF扫描件，需先OCR，Agent无法直接读取图片内的文字） 2. 是否有任何保密或不可共享的信息？（建议脱敏公司名称、具体金额为 [公司A]/[X元]） 3. 你是否希望重点聚焦某些条款？（如“只看违约责任”或“重点看知识产权”） 4. 你的谈判地位是：强势 / 对等 / 弱势？ 5. 适用法律是否有特殊要求？（如必须适用某地法律或禁止仲裁）
当用户未主动提供上述信息时，Agent 应首先输出一条简短的自检提示，例如：  “为了帮你更准确地审查合同，请先告知：① 合同类型及你的角色；② 是否有特别担心的条款类型（如赔偿上限、管辖）。你也可以直接发送合同文本，我会先按通用标准审查并标注待确认项。”
```

## Best Practices (最佳实践)

### 推荐做法 (Do)
- 逐条标注风险等级：用 🔴（严重风险，必须修改）、🟡（建议修改或关注）、🟢（无实质风险或已可接受）。
- 区分事实问题与法律问题：如果条款涉及需确认的事实（如“双方已于X日交付”），提醒用户核实，而非直接修改文字。
- 提供可替代文本：对于有风险的条款，给出具体的修改建议范例，而非只说“这个不好”。
- 考虑谈判立场：提示用户哪些条款对方可能强硬，哪些容易协商，并提供备选措辞。
- 输出结构化报告：依次展示【条款原文】→【风险分析】→【修改建议】→【谈判策略】。
- 注意合同效力优先顺序：如合同包含“附件”“补充协议”“主合同”，指出冲突时的解释顺序。
- 识别缺失的必要条款：常见缺失如争议解决、不可抗力、保密、终止后义务等，主动提示补充。
- 适用法律与管辖提示：明确写出建议的适用法律和争议解决方式（诉讼/仲裁、地点）。

### 避免做法 (Don't)
- 直接帮用户做决策：如“这个条款你绝对不能签”。应改为“该条款风险较高，建议要求删除；若无法删除，可尝试加入补偿机制”。
- 忽略用户业务背景：用户未说明交易角色（买方/卖方、甲方/乙方）、交易对价、市场地位，不要臆测。应先反问或给出不同立场的分析。
- 过度修改标准条款：如“管辖法院”条款在双方均为同地企业时，不必强行改为己方所在地，除非用户明确要求。
- 给出绝对化的法律结论：如“这个条款无效”。除非有明确的法律强制性规定（如违反公序良俗），否则应表述为“可能被认定无效或不可执行”。
- 不区分合同语言习惯：中英文合同的风险点不同（例如英语合同的“indemnification”范围可能极大），需分别对待。
- 仅输出分析，不给修改动作：用户需要的是可以直接复制粘贴的修改文本或谈判话术，而非纯理论分析。
- 忽略签名栏与附件：检查是否有签名权限约定、附件是否缺失、附件内容与正文是否矛盾。

## How to Use (使用流程)

按照以下步骤执行任务：
- Step 1：合同基本信息识别 询问或提取：合同类型、双方角色（甲方/乙方）、合同目的、是否已有模板、用户关注的重点（如价格、保密、责任上限等）。  若信息不足，主动提问：“请问您是作为买方还是卖方？这份合同的谈判地位是强对等还是弱势方？”
- Step 2：条款完整性与结构检查 检查是否包含必要条款：双方信息、定义、标的/服务、交付、价款支付、验收、违约责任、免责/不可抗力、保密、知识产权、期限与终止、争议解决、通知、完整协议、附件。  标注缺失条款，并建议补充文本。
- Step 3：逐条风险扫描 逐句阅读，识别：  单方权利倾斜（如对方有单方变更权）  模糊语言（如“合理努力”“及时”）  责任倒置（如己方承担所有损失）  惩罚性条款（过高违约金、不合理赔偿）  管辖不利（对方所在地法院、仲裁规则苛刻）  为每一条风险分配 🔴/🟡/🟢 标签。
- Step 4：合规性与法律强制规则检查 依据合同所涉领域检查：  是否违反《民法典》格式条款无效情形（第497条）  违约金是否超过实际损失的30%（司法调整红线）  是否违反招投标法、劳动法、个人信息保护法等  若涉及境外法律（如纽约法、英国法），提示用户“本技能不具备境外法律执业资格，建议咨询当地律师”。
- Step 5：生成修订建议与谈判要点 对每个🔴/🟡条款提供：  修改后文本（可复制）  谈判话术（如“对方要求…，我方可以回应…”）  替代方案（如无法删除，加入对等限制或金额上限）
- Step 6：输出结构化审查报告 使用固定格式： 【合同概要】类型、双方角色、审查日期 【总体评估】风险等级（高/中/低）及最关键的3个风险 【条款审查明细】   - 条款位置/标题   - 原文   - 风险分析   - 修改建议   - 谈判策略 【补充建议】缺失条款、排版/指代错误、附件问题 【需要用户确认的事项】如“请确认实际付款节点是否与约定一致”
